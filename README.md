# monaka

もなかのHP制作。

## 開発

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

公開サイト（GitHub Pages）は [https://kathysamurai.github.io/monaka/](https://kathysamurai.github.io/monaka/) です。`main` への push で自動更新されます。

## スナップショット写真

TOPの「人は、もともと、おもしろい。」の下は、`public/images/` に入れた写真を並べます。

jpg / png / webp を `public/images/` に入れたあと、縮小サムネイルを作ります。

```bash
npm run thumbs
```
